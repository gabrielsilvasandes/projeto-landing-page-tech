# 🌐 TechNova

Landing page moderna e totalmente responsiva desenvolvida com **HTML5**, **CSS3** e **JavaScript**, focada em **UI/UX**, **design clean** e **interação dinâmica com tema claro e escuro**.

https://gabrielsilvasandes.github.io/projeto-landing-page-tech/

## 🚀 Funcionalidades

- Alternância de tema (modo claro/escuro) com ícones dinâmicos.  
- Layout responsivo adaptado para **desktop, tablet e mobile**.  
- Seções estruturadas seguindo a **hierarquia do DOM**.  
- Efeitos visuais com **transições suaves** e **hover responsivo**.  
- Ícones via **Bootstrap Icons** e **paleta moderna** baseada em tons frios e neutros.  
- Avaliações com **estrelas dinâmicas** e depoimentos simulados.

## 🛠️ Tecnologias Utilizadas

- **HTML5**  
- **CSS3** (com variáveis de cor, gradientes e media queries)  
- **JavaScript** (manipulação de DOM e troca dinâmica de imagens)  
- **Bootstrap 5**

## 💡 Objetivo

Este projeto foi desenvolvido com o objetivo de **demonstrar habilidades práticas em front-end**, boas práticas de **semântica HTML**, **organização de CSS** e **integração de interações JS**, servindo como parte do meu portfólio profissional.
